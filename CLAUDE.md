# Como a IA trabalha neste repositório

1. Comece pelo `ESTADO.md` e pelo `docs/PRE_REGISTRO.md`. A doutrina está em `.cursor/rules/geopolitica-eleicao-2026-fundamentos.mdc`.
2. Regra mudou? Só por emenda datada na §13 do pré-registro, dizendo se veio antes ou depois de ver o dado.
3. Os dois lados, sempre: toda pergunta roda pelas lentes L, F1 e F2, cada uma dada como verdadeira, procurando o que derrubaria cada uma.
4. Número só de arquivo com hash em `dados/MANIFESTO.json`; no git, texto extraído, nunca HTML bruto.
5. Relatório e gráficos por script; número à mão, nunca.
6. Registro do projeto no repositório de documentação: `contexto/projetos-externos/GEOPOLITICA_ELEICAO_2026_PLANO.md`.
